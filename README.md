# AI 学习仓库

这是我的个人 AI 学习路线与实践记录。目标是从数学基础出发，逐步掌握机器学习、深度学习、大语言模型和 AI 工程实践。

## 学习主线

1. [数学基础](./01-数学基础/README.md)：线性代数、微积分、概率统计、优化
2. [机器学习](./02-机器学习/README.md)：监督学习、无监督学习、模型评估
3. [深度学习](./03-深度学习/README.md)：神经网络、CNN、RNN、Transformer
4. [大语言模型](./04-大语言模型/README.md)：GPT、Embedding、RAG、微调、Agent
5. [AI 工程实践](./05-AI工程实践/README.md)：API、测试、部署、MLOps
6. [学习记录](./06-学习记录/README.md)：每周总结、问题、复盘
7. [项目](./项目/README.md)：把知识转化成可运行的作品

## 推荐开始顺序

- 第一阶段：`01-数学基础` 中的 Datawhale《人工智能的数学基础》
- 第二阶段：`02-机器学习` 中的 Microsoft ML-For-Beginners
- 第三阶段：`03-深度学习` 中的《动手学深度学习》中文版
- 第四阶段：Karpathy 的 neural networks: zero to hero
- 第五阶段：`04-大语言模型` 中的 LLMs-from-scratch 和 LLM-Universe
- 第六阶段：`05-AI工程实践` 中的 Made With ML

## 学习原则

- 每次只维护一个主线，避免同时打开太多课程。
- 每学完一个主题，至少完成一个小练习或可运行程序。
- 记录“我理解了什么、哪里不懂、下一步做什么”。
- 第三方仓库只作为外部资料引用，不直接复制其代码和教材文件。

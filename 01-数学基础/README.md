# 01 数学基础

## 推荐顺序

1. 线性代数：向量、矩阵、线性变换、特征值、SVD
2. 微积分：导数、偏导数、梯度、链式法则
3. 概率统计：随机变量、分布、期望、方差、贝叶斯、最大似然
4. 优化：梯度下降、凸优化、正则化
5. 信息论：熵、交叉熵、KL 散度
